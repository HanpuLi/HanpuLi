# Hanpu Li · 李函璞

Writer and researcher in London. I use GitHub for the parts of my work that benefit from being inspectable: research code and archived outputs, spatial analysis, publishing infrastructure, and local-first tools. My writing and photography are indexed on my portfolio. I also publish as **Caitlyn Lye**.

**[Portfolio](https://hanpuli.github.io/)** · **[LinkedIn](https://www.linkedin.com/in/hanpuli/)** · **[Academia.edu](https://independent.academia.edu/LiHanpu)**

## Selected work

**Research**

- **[The Material Footprint of Virtual Production](https://github.com/HanpuLi/shepperton-spatial-audit)**: a reproducible spatial audit of the Shepperton Studios expansion using OpenStreetMap, Earth observation and planning evidence.
- **[On Takashi Miike’s First Love](https://hanpuli.github.io/writing/first-love/)**: a long-form film study supported by a separate **[methods and verification repository](https://github.com/HanpuLi/first-love-verification)**.
- **[London Chinatown Food & Beverage Analysis](https://github.com/HanpuLi/London_chinatown)**: an archived OpenStreetMap-based spatial analysis with a public interactive output.

**Publishing**

- **[Poetry Voucher](https://hanpuli.github.io/poetry-voucher/)**: an independent artist publication and browser-based publishing system built around multilingual reading, accessibility and print-oriented output.

**Systems**

- **[ScopeRail](https://github.com/HanpuLi/scoperail)**: a scoped local-execution runtime for MCP clients on macOS, with explicit workspace capabilities, sandboxed processes, browser/native UI control, audit and provenance.
- **[PhoSignal](https://github.com/HanpuLi/phosignal)**: a local-first macOS status light for ChatGPT, Codex and Claude Code using the keyboard backlight and MagSafe LED.

## Methods and tools

Python, R, geospatial and remote-sensing workflows, OpenStreetMap, HTML/CSS/JavaScript, Playwright, and macOS automation. Where a claim depends on computation or data, I keep the source material, generated outputs and verification path explicit.
